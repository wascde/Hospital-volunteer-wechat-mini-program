# 医院志愿者微信小程序

## 项目简介
这是一个为医院志愿者设计的微信小程序，帮助志愿者快速解答患者在医院中遇到的各种问题，提高志愿服务效率和质量。

## 核心功能

### 1. 科室查询
- 根据患者描述的症状或疾病名称，快速查询对应的就诊科室
- 保存最近查询记录，方便快速再次查询

### 2. 医院地图
- 查看医院各楼层布局
- 展示各科室位置和设施分布
- 提供科室详细信息

### 3. 志愿者指南
- 服务规范：志愿者服务的基本规范和要求
- 应急处理：常见紧急情况的处理方法
- 沟通技巧：与患者沟通的技巧和注意事项

### 4. 常见问题
- 按类别展示患者经常询问的问题
- 支持关键词搜索功能
- 提供详细的问题解答

### 5. 个人中心
- 展示志愿者个人信息和服务统计
- 查看服务记录和培训证书
- 小程序设置

## 开发环境

### 1. 开发工具
- 微信开发者工具（最新版本）

### 2. 技术栈
- 微信小程序原生开发框架
- JavaScript
- WXML
- WXSS

### 3. 依赖
- 无外部依赖（使用微信小程序原生API）

## 快速开始

1. **安装微信开发者工具**
   - 下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   - 安装并登录开发者工具

2. **导入项目**
   - 打开微信开发者工具
   - 点击「导入项目」
   - 填写项目信息：
     - 项目名称：医院志愿者小程序
     - 目录：选择本项目的根目录
     - AppID：输入您的小程序AppID
     - 开发模式：选择「小程序」
     - 后端服务：根据需求选择

3. **运行项目**
   - 点击「编译」按钮，编译项目
   - 在模拟器中查看效果
   - 点击「真机调试」，使用微信扫码进行真机测试

## 开发说明

### 数据管理
- 目前数据存储在app.js的globalData中，实际项目中可以迁移到云开发或自己的服务器

### 地图功能
- 目前使用模拟地图，实际项目中可以集成腾讯地图API

### 样式规范
- 使用app.wxss定义全局样式
- 页面样式尽量独立，避免样式冲突

## 注意事项

1. 请确保您已注册微信小程序账号并获取了AppID
2. 开发前请仔细阅读微信小程序开发文档
3. 真机调试时需要使用与注册AppID绑定的微信账号
4. 上线前需要完成微信小程序的审核流程
