# 微信小程序注册与基本配置指南

## 一、注册微信小程序账号

### 1. 访问微信公众平台
- 打开浏览器，访问微信公众平台官网：https://mp.weixin.qq.com/
- 点击右上角的「立即注册」按钮

### 2. 选择注册类型
- 在注册页面，选择「小程序」作为注册类型

### 3. 填写基本信息
- 邮箱：输入未注册过微信公众号的邮箱
- 密码：设置8-20位的密码，包含字母、数字和符号
- 验证码：输入页面显示的验证码
- 勾选同意《微信公众平台服务协议》
- 点击「注册」按钮

### 4. 激活邮箱
- 登录填写的邮箱，查收微信公众平台发送的激活邮件
- 点击邮件中的激活链接，完成邮箱激活

### 5. 选择主体类型
- 激活后，选择小程序的主体类型，对于医院志愿者小程序，建议选择「企业/政府/其他组织」
- 点击「继续」按钮

## 二、完成主体信息登记

### 1. 填写主体信息
- 主体名称：输入医院的全称
- 组织机构代码：输入医院的组织机构代码
- 法定代表人姓名：输入医院法定代表人姓名
- 证件类型：选择「营业执照」或「组织机构代码证」
- 证件号码：输入对应证件的号码
- 注册地址：输入医院的注册地址

### 2. 上传证明材料
- 上传营业执照或组织机构代码证的扫描件
- 上传法定代表人身份证正反面扫描件

### 3. 填写管理员信息
- 管理员姓名：输入负责小程序管理的人员姓名
- 管理员身份证号码：输入管理员的身份证号码
- 管理员手机：输入管理员的手机号码
- 短信验证码：点击「获取验证码」，输入手机收到的验证码

### 4. 提交审核
- 确认所有信息无误后，点击「提交」按钮
- 等待微信官方审核，审核时间一般为1-3个工作日

## 三、基本配置

### 1. 获取AppID和AppSecret
- 审核通过后，登录微信公众平台
- 在左侧菜单中点击「开发」->「开发设置」
- 在「开发者ID」部分，可以查看AppID
- 点击「生成」按钮获取AppSecret（需管理员扫码验证）

### 2. 配置服务器域名
- 在「开发设置」页面，找到「服务器域名」部分
- 点击「修改」按钮，配置以下域名：
  - request合法域名：根据实际后端服务器配置
  - socket合法域名：根据实际需要配置
  - uploadFile合法域名：用于文件上传
  - downloadFile合法域名：用于文件下载
- 配置完成后点击「保存并提交」

### 3. 配置业务域名
- 在「设置」->「基本设置」页面，找到「业务域名」部分
- 点击「修改」按钮，添加小程序中需要跳转的业务域名
- 需要下载验证文件并上传到对应域名的服务器根目录

### 4. 设置小程序信息
- 在「设置」->「基本设置」页面，设置小程序的基本信息：
  - 小程序名称：输入医院志愿者小程序的名称
  - 小程序头像：上传小程序的头像
  - 小程序介绍：输入小程序的功能介绍
  - 服务类目：选择「医疗健康」相关的服务类目
  - 申请理由：填写小程序的使用场景和申请理由

## 四、注意事项

1. 请确保提供的所有信息真实有效，否则可能导致审核不通过
2. AppID和AppSecret是开发小程序的重要凭证，请妥善保管
3. 服务器域名配置后需要等待一段时间才能生效
4. 服务类目需要根据实际功能选择，可能需要提供相关资质证明

完成以上步骤后，您的微信小程序账号就注册完成并进行了基本配置，可以开始进行开发了。
