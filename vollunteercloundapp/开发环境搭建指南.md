# 微信小程序开发环境搭建指南

## 一、安装微信开发者工具

### 1. 下载开发者工具
- 访问微信开发者工具官方下载页面：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
- 根据您的操作系统选择对应的安装包（Windows或macOS）
- 点击下载按钮，保存安装包到本地

### 2. 安装开发者工具
- **Windows系统**：
  - 双击下载的安装包（.exe文件）
  - 按照安装向导的提示进行安装
  - 选择安装路径，建议使用默认路径
  - 点击「安装」按钮，等待安装完成
  - 安装完成后，点击「完成」按钮

- **macOS系统**：
  - 双击下载的安装包（.dmg文件）
  - 将微信开发者工具拖动到「应用程序」文件夹中
  - 打开「应用程序」文件夹，双击微信开发者工具图标启动

### 3. 首次启动配置
- 启动微信开发者工具
- 使用微信扫码登录
- 选择「小程序」开发模式
- 进入开发者工具主界面

## 二、创建小程序项目

### 1. 初始化项目
- 在开发者工具主界面，点击「新建项目」按钮
- 填写项目信息：
  - 项目名称：医院志愿者小程序
  - 目录：选择本地项目保存路径（如d:\vollunteercloundapp）
  - AppID：输入之前注册的小程序AppID
  - 开发模式：选择「小程序」
  - 后端服务：根据需求选择，建议先选择「不使用云服务」
  - 模板选择：选择「JavaScript - 基础模板」
- 点击「确定」按钮，创建项目

### 2. 项目结构介绍
项目创建完成后，会生成以下主要文件和目录：

```
├── app.js           // 小程序入口文件
├── app.json         // 全局配置文件
├── app.wxss         // 全局样式文件
├── pages/           // 页面目录
│   ├── index/       // 首页
│   │   ├── index.js     // 首页逻辑
│   │   ├── index.wxml   // 首页结构
│   │   ├── index.wxss   // 首页样式
│   │   └── index.json   // 首页配置
│   └── logs/        // 日志页
│       ├── logs.js      // 日志页逻辑
│       ├── logs.wxml    // 日志页结构
│       ├── logs.wxss    // 日志页样式
│       └── logs.json    // 日志页配置
├── utils/           // 工具函数目录
│   └── util.js      // 通用工具函数
└── project.config.json  // 项目配置文件
```

- 如果需要使用第三方库，可以通过npm安装：
  - 点击开发者工具顶部菜单「工具」->「构建npm」
  - 在项目根目录下执行npm命令安装依赖

## 四、开发前准备

### 1. 配置ESLint（可选）
- 为了提高代码质量，可以配置ESLint：
  - 在项目根目录下创建`.eslintrc.js`文件
  - 配置ESLint规则

### 2. 创建图标资源
- 准备小程序所需的图标资源，放在`images`目录下：
  - 底部导航栏图标
  - 功能按钮图标
  - 其他UI元素图标

### 3. 准备数据
- 收集医院科室信息、地图数据、常见问题等内容
- 设计数据结构，便于后续开发使用

## 五、开发工具使用技巧

### 1. 模拟器使用
- 在开发者工具中，可以使用模拟器预览小程序效果
- 可以切换不同的设备型号和系统版本

### 2. 调试功能
- 使用「调试器」面板进行代码调试
- 查看控制台输出、网络请求、存储数据等

### 3. 真机调试
- 点击「真机调试」按钮，使用微信扫码进行真机测试
- 可以实时查看真机上的运行效果和调试信息

### 4. 代码上传
- 开发完成后，点击「上传」按钮将代码上传到微信服务器
- 可以在微信公众平台查看上传的版本

## 六、注意事项

1. 开发过程中要遵循微信小程序的开发规范
2. 注意代码的可读性和可维护性
3. 定期备份项目文件
4. 真机调试是确保小程序正常运行的重要环节
5. 及时关注微信小程序官方文档的更新

完成以上步骤后，您的微信小程序开发环境就搭建完成了，可以开始进行具体功能的开发。
